## 🫧 About Me

<img align="right" src="https://raw.githubusercontent.com/Ishita-Si/Ishita-Si/main/assets/smile.png" width="200"/>

Hello, I'm **Ishita Singh** — an AI/ML developer passionate about building intelligent systems that actually work in the real world. I specialize in:

- **Agentic AI** — autonomous pipelines, multi-agent orchestration, tool-calling systems
- **NLP** — text classification, semantic search, transformers, LLM fine-tuning
- **Machine Learning** — supervised/unsupervised learning, deep learning, computer vision
- **Frontend** — building clean, responsive UIs that bring AI to users

> *Committed to continuous learning and excellence within the tech community.*
